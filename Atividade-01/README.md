# atividade 1 - Quem é quem?
🎭 Quem é Quem?

A atividade “Quem é Quem?” é uma dinâmica em grupo na qual são apresentadas curiosidades sobre as integrantes, sem revelar quem é a pessoa.

Os colegas devem observar as informações e tentar descobrir a quem cada característica pertence.

Foram abordados três temas principais:

🎨 Hobby

💭 Uma lembrança boa

❤️ Algo que não vive sem

A atividade tem como objetivo promover interação, diversão e conhecimento entre os colegas, além de trabalhar a ideia de como formamos primeiras impressões a partir de poucas informações.

Ferramentas utilizadas: Canva e Google Forms.
